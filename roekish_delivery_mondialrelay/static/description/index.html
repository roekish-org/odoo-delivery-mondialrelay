Mondial Relay for Odoo 19: Point Relais, Locker, home delivery

Rate shipments, generate labels, track parcels and offer Point Relais delivery from Odoo.

Features

RatingDelivery price computed from a Mondial Relay tariff grid (weight by zone) or from Odoo's native pricing rules.
Delivery timeAnnounced delivery time in working days (minimum and maximum), set on the carrier and overridable per zone in the tariff grid. Returned with every quote and shown in the shipping wizard, so carriers can be compared on cost and speed.
LabelsShipment and label creation through the Mondial Relay Connect API (production or sandbox): PDF 10x15, A4, A5 or ZPL 10x15, with the shipment number stored on the delivery order.
TrackingA Mondial Relay tracking link is exposed to the customer.
Points RelaisSearch nearby Points Relais and Lockers and select one on the quotation or the delivery order, propagated on confirmation and sent on the shipment.
ModesPoint Relais, Point Relais XL / Locker, home delivery and delivery at the merchant; collection at the merchant or drop in a Point Relais.

Carriers and zones

Three ready-to-use carriers ship with indicative 2026 rates as editable demo data. Mondial Relay business rates are negotiated per contract: replace the demo grids with yours.

Security

  • The web service private key and the Connect API credentials are restricted to the Mondial Relay Administrator group, and secrets are masked in error messages.
  • Fine-grained access rights with dedicated User and Administrator groups.
  • Multi-company isolation on the tariff grids.

Requirements

The module builds on Odoo's native delivery framework. Rating and labels work with no external library: the Connect API is called with requests, shipped with Odoo. Point Relais search uses zeep, optional and imported on demand.

Deploy the module on the addons_path (Odoo.sh or On-Premise). The Apps > Import Module zip upload is data-only and cannot install a module that ships Python models. On Odoo Online (SaaS) Python libraries cannot be installed either, so the live Point Relais search needs Odoo.sh or On-Premise, where zeep is available.
