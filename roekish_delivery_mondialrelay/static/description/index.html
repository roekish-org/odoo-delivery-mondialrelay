Mondial Relay for Odoo 19: Point Relais, Locker, home delivery

Rate shipments, generate labels, track parcels and offer Point Relais delivery, straight from Odoo.

Features

  • Rating: delivery price computed from a Mondial Relay tariff grid (weight by zone) or from Odoo's native pricing rules.
  • Labels: shipment and label creation through the Mondial Relay Connect API (production or sandbox), PDF 10x15, A4, A5 or ZPL code, with the shipment number stored on the delivery order.
  • Tracking: a Mondial Relay tracking link is exposed to the customer.
  • Points Relais: search nearby Points Relais and Lockers and select one on the sale order or the delivery order, propagated on confirmation and sent on the shipment.
  • Modes: Point Relais, Point Relais XL / Locker, home delivery and merchant delivery; collection at the merchant or drop in a Point Relais.

Carriers and zones

Three ready-to-use carriers ship with indicative 2026 rates, which you replace with your own contract rates: Point Relais, Locker and Domicile. Zones cover metropolitan France, Europe zone 1 (Belgium, Luxembourg, Netherlands, Germany), Europe zone 2 (Spain, United Kingdom) and Europe zone 3 (Italy, Portugal, Austria).

Security

  • The web service private key and the Connect API credentials are restricted to the Mondial Relay Administrator group, and secrets are masked in error messages.
  • Fine-grained access rights with dedicated User and Administrator groups.
  • Multi-company isolation on the tariff grids.

Requirements

The module builds on Odoo's native delivery framework. Rating and labels work with no external library: the Connect API is called with requests, shipped with Odoo. Point Relais search uses zeep, optional and imported on demand.

Deploy the module on the addons_path (Odoo.sh or On-Premise). The Apps > Import Module zip upload is data-only and cannot install a module that ships Python models. On Odoo Online (SaaS) Python libraries cannot be installed either, so the live Point Relais search needs Odoo.sh or On-Premise, where zeep is available.
