# Politique de sécurité

## Versions supportées

| Version | Supportée |
|---------|-----------|
| 19.0.x  | oui       |
| < 19.0  | non       |

## Signaler une faille

N'ouvrez pas d'issue publique pour une vulnérabilité.

Utilisez le signalement privé de GitHub : onglet **Security** du dépôt, puis
**Report a vulnerability**. Le rapport reste confidentiel entre vous et les
mainteneurs.

Merci d'inclure :

- une description de la faille et de son impact,
- les étapes pour la reproduire,
- la version du module et d'Odoo.

Nous accusons réception sous 5 jours ouvrés et vous tenons informé du
correctif. Aucune donnée sensible (identifiants Mondial Relay, clés) ne doit
figurer dans un rapport public.
